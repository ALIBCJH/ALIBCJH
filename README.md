## About Me

I am a **Senior Backend Engineer and Cloud Engineer** specializing in the design, development, and operation of scalable software systems.

My work spans **backend architecture, distributed applications, cloud-native infrastructure, container orchestration, and production engineering**.

I focus on building systems that are secure, maintainable, observable, and engineered for long-term reliability.

My engineering expertise includes:

- **Backend Engineering:** API design, service architecture, authentication, third-party integrations, and database-driven applications.
- **Cloud Engineering:** Containerized infrastructure, Kubernetes orchestration, Linux environments, and deployment automation.
- **Distributed Systems:** Service communication, caching, asynchronous processing, and performance optimization.
- **AI Infrastructure:** GPU-backed inference, model serving, workload orchestration, and observability.
